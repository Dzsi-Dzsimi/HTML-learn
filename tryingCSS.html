Hue saturation lightness

HSLA is a CSS color model that defines colors using four values: Hue, Saturation, Lightness, and Alpha.

  • Hue: A degree on the color wheel from 0 to 360 (e.g., 0/360 is red, 120 is green, 240 is blue).
  • Saturation: A percentage from 0% to 100%, where 0% is gray and 100% is full color intensity.
  • Lightness: A percentage from 0% to 100%, where 0% is black, 100% is white, and 50% is the normal color.
  • Alpha: A number between 0.0 and 1.0, where 0.0 is fully transparent and 1.0 is fully opaque.
