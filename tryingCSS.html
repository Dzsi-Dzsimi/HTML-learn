Hue saturation lightness

HSLA is a CSS color model that defines colors using four values: Hue, Saturation, Lightness, and Alpha.

  • Hue: A degree on the color wheel from 0 to 360 (e.g., 0/360 is red, 120 is green, 240 is blue).
  • Saturation: A percentage from 0% to 100%, where 0% is gray and 100% is full color intensity.
  • Lightness: A percentage from 0% to 100%, where 0% is black, 100% is white, and 50% is the normal color.
  • Alpha: A number between 0.0 and 1.0, where 0.0 is fully transparent and 1.0 is fully opaque.

Overflows:

overflow = property that sets the desired behaviour when content does not fit in the parent element box (overflows):

  • overflow: visible = if any elements were to overflow, allow it to do so
  • overflow: hidden = if any content overflows, it is hidden.
  • overflow: clip = used alongside overflow-clip-margin: size; to determine how much content is shown above overflow
  • overflow: scroll = makes horizontal and vertical overflow bars
  • overflow: auto = makes scrollbar only if needed, so for example horizontal might not be needed

More properties:

  • display: block; - Takes up the full available width and starts on a new line. (e.g. div, p, h1)
  • display: inline; - Only takes up as much width as necessary. Elements sit next to each other. Width and height cannot be set normally. (e.g. span, a)
  • display: inline-block; - Sits next to other inline elements but allows you to set width and height.
  • display: none; - Completely hides the element and removes it from the page layout.
  • display: flex; - Creates a flexible layout, making it easier to align and distribute elements horizontally or vertically.
  • display: grid; - Creates a grid-based layout with rows and columns.
  • display: table; - Makes an element behave like an HTML table.
