This project is dedicated to learning HTML. The pages include a home page, a page dedicated to rock hyraxes, a page with content from what I learned in a course.

The course I used to create this website was: https://youtu.be/HGTJBPNC-Gw 
The website can be accessed here: https://dzsi-dzsimi.github.io/HTML-learn/
- This was published through GitPages, a very beginner friendly form of publishing a website

**Home: Introduction and navigation.**
- Rock Hyraxes: A page dedicated to rock hyraxes, including pictures and interesting facts.
- HTML learn: Practical examples of HTML elements and features I learned throughout the course.
- Miscellaneous: other pages made for practicing HTML and also to follow through the course.

There was minimal css used in this, although the main aim was for learning HTML.
There was also minimal JavaScript used to create functionality (just for a button to work)
Future goals:
- Use CSS to style ALL pages. (Includes learning how to use CSS)
- Use JavaScript to create functionality for the webpage (things such as buttons)
